# VIGILIS LAB

**Интеллектуальная система мониторинга и приоритизации финансовых рисков малого и среднего бизнеса.**

Учебный функциональный прототип веб-приложения и методика финансового анализа.

---

## Проблема

Финансовые данные малого бизнеса разбросаны по файлам и системам. Сложно не только найти отклонения, но и понять, как они связаны и что проверять первым. Задержка оплаты от клиента может изменить прогноз остатков и создать риск неисполнения обязательств перед поставщиком — обычные предупреждения эту цепочку не объясняют.

## Решение

VIGILIS LAB собирает контрольные сигналы в понятную картину:

**признак риска → возможное последствие → объяснимый приоритет → действие для проверки.**

- Импорт Excel-книги из 5 листов (операции, бюджеты, дебиторка, денежный план, настройки).
- Четыре сигнала: возможный дубль платежа, превышение бюджета, просроченная дебиторка, прогнозируемый кассовый разрыв.
- Реестр и карточка предупреждения: источник, основание, дата, сумма, следующее действие.
- Объяснимый приоритет (высокий / средний / низкий) + отдельный статус достаточности данных.
- Одна связанная цепочка и сравнение базового плана с задержкой поступления на 7 дней.

## Границы

Сигнал — **основание для проверки, а не доказательство нарушения или мошенничества**. Прототип работает на вымышленных учебных данных.

Не входят: реальные банковские счета, интеграция с 1С, конфиденциальные данные, ML/нейросеть, платная инфраструктура, коммерческий запуск. Синтетические данные подтверждают работоспособность на учебных условиях, но не эффект на реальном бизнесе.

## Для кого

- **Собственник / руководитель** — краткая картина угроз и очерёдность проверки.
- **Финансовый менеджер / аналитик** — контроль остатков, бюджета, задолженности.
- **Бухгалтер / контролёр** — дубли, отклонения, просрочки с переходом к исходной записи.
- **Специалист по экономической безопасности** — анализ признаков без автоматического обвинения.

## Принципы

- Сначала один сквозной путь на учебных данных, затем расширение.
- Локальный запуск без зависимости от интернета.
- Недостаток данных показывается как «недостаточно данных», а не нулями.
- Сигналы — основания для проверки специалистом.
